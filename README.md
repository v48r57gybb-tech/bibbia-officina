# Bibbia dell’Officina

Prototipo offline per archiviare casi di lavorazione: cliente, pezzo, materiale, macchina, operazione, utensile, parametri, anomalie e risultati.

## Uso

Apri l’app, crea un caso e salvalo. I dati restano nel browser del dispositivo. Usa **Esporta backup** per salvare un file JSON e **Importa** per ripristinarlo.

## Installazione

Su telefono: apri il link, poi dal menu del browser scegli **Aggiungi a schermata Home**.

## Pubblicazione

Il workflow `.github/workflows/pages.yml` pubblica automaticamente il contenuto del branch `main` su GitHub Pages.
